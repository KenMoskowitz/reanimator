# CINEMATIC SHORT AD SCRIPT SYSTEM

## WORLD-CLASS + MODERN RETENTION + GENRE DYNAMIC

---

# PURPOSE

This framework creates cinematic short ad scripts optimized for:

- Audience retention
- Modern cinematic storytelling
- Emotional intensity
- Genre awareness
- Relatability
- Twist-driven storytelling

The subject and stakes are flexible.

Stories may explore any:

- Human desire
- Fear
- Crisis
- Conflict
- Absurd situation

They are not limited to money or career topics.

---

# USAGE INSTRUCTIONS

When creating a cinematic short ad:

- Follow the structure and timecodes.
- Label each section clearly.
- Keep total runtime approximately 60 seconds.
- Use modern relatable language.
- Make stakes highly personal.
- Include foreshadowing.
- Include twist payoff.
- State the visible goal.

## Title Format

**[Main Character First Name] + [3–5 words describing the plot]**

Example format:

> Maya Misses the Last Train

---

# 00:00–00:10 - HOOK

## Setup + Stakes + Visible Goal

Requirements:

- Instantly grab attention.
- Call out audience pain, obsession, fear, or desire.
- Introduce a nightmare-level challenge.

State:

**[VISIBLE GOAL]**

The visible goal should contain:

- A specific mission
- A ticking clock
- Extremely high personal stakes

Example structure:

> [VISIBLE GOAL] - I need to save my cat from this tree in the next 12 minutes or my brother is going to be emotionally scarred for life.

End the section with a cliffhanger.

The viewer should need to know what happens.

---

# 00:10–00:35 - FORESHADOW + VALUE DISCOVERY

Escalate rapidly.

Use:

- Difficult problems
- Visual chaos
- Emotional chaos
- Physical chaos

Foreshadow:

- Hidden opportunity
- Hidden mechanism
- Possible solution

Do not fully explain the payoff yet.

---

# 00:35–00:45 - ALL IS LOST / SOLUTION TRIGGER

Present the darkest point.

The main character:

- Emotionally breaks
- Physically breaks
- Fails
- Gets trapped
- Loses the obvious solution

Then:

- Reveal
- Activate
- Discover

the solution trigger.

---

# 00:45–00:55 - CLIMAX

## Solution Applied + Redemption + Twist Payoff

- Apply the solution.
- Move quickly.
- Deliver success, reversal, or transformation.
- Pay off foreshadowing.
- Deliver the twist.
- Where useful, connect the ending to the audience or format itself.

---

# 00:55–01:00 - TRANSFORMATION

Show the transformed protagonist.

End with:

- Strong CTA
- Power close
- Meta hook
- Punchline
- Consequence for the viewer

---

# WRITING RULES

- Use the selected Reanimator audio mode.
- If operating under the source framework's original ad mode, first-person MC voiceover is preferred.
- Language must feel modern and relatable.
- Genre execution must match genre expectations.
- Stakes must be high, emotional, and personal.
- Foreshadowing is required.
- Twist payoff is required.
- CTA should be direct when the project is an ad.
- Keep labeled timecodes.
