## Read on demand (do not load everything up front)

Before writing, read the file that matches the job:

- Story shape for a 60-second film or ad: 03_STORY/CINEMATIC_AD_STRUCTURE.md and 03_STORY/ESSENTIAL_STORY_STRUCTURE.md
- Longer story or sequence work: 03_STORY/LONG_FORM_SEQUENCE_STRUCTURE.md
- Any hook: 04_HOOKS/SIX_HOOK_ARCHETYPES.md and 04_HOOKS/FOUR_HOOK_FAILURES.md
- Any selling copy: 05_MARKETING/COMPLIANT_AD_COPY_GUIDE.md
- Skool community offers: 05_MARKETING/SKOOL_ABOUT_PAGE_EXAMPLE.md and 05_MARKETING/PAIN_POINT_TEMPLATE.md
- Client research, pricing, market work: 06_BUSINESS_RESEARCH/MASTER_BUSINESS_CUSTOMER_RESEARCH_PROMPT_PACK.md (use only the modules that fit the job)
- Image styles and storyboards: 02_VISUAL_STYLE/REANIMATOR_IMAGE_STYLE_LIBRARY.md

Ignore the UPLOAD_TXT folder. It holds duplicate copies for uploading elsewhere.

## How a session starts

When Ken says "Go" or starts a new creative session, present the seven project paths from the master instructions, exactly as written, then wait. Do not start writing until he picks one and the audio mode is locked.

## Saving project state

Every project gets its own folder at projects/<project-name>/ with a state.md file. Copy the fields from 00_CORE/PROJECT_STATE_TEMPLATE.md.

- Update state.md whenever something locks: audio mode, script, character profiles, series bible, season map, each episode, style, storyboard.
- Save each locked script, bible, and season map as its own markdown file in that project folder.
- At the start of a session, if projects/ has folders, ask which one to continue before offering a new project.
- Never overwrite a locked field without an explicit request from Ken.

## Images

Claude Code does not make images by itself. After a style is locked, write the storyboard sheet prompt and each frame prompt as text, one frame at a time, in the exact style language from the style library. Save each to projects/<project-name>/frames/. If an image tool is connected in the session, offer to use it, but still deliver one frame at a time.

## Ken's rules

- No em dashes. Ever. Use a period, comma, or hyphen.
- No cliches, no jargon, plain words. Sixth-grade reading level for copy.
- No invented statistics and no invented quotes from real people.
- Light-colored design only for anything visual built for him.
- Any byline or footer reads: Ken "Spanky" Moskowitz | Ad Zombies | adzombies.com. Never add a city.
- Write like he talks. Fun analogies are welcome.
- Only claim an Ad Zombies offer or price in a script if Ken has confirmed it is live. Ask first.
