# REANIMATOR 10 - REBUILD PACKAGE

Rebuilt as **Reanimator 10** for Ad Zombies.

## Folder map

- `00_CORE/` : master instructions (behavior layer) and the project state template
- `01_SERIES/` : the Vertical Series Bible template
- `02_VISUAL_STYLE/` : the nine-style image library
- `03_STORY/` : cinematic ad structure, essential story structure, long-form sequence structure
- `04_HOOKS/` : six hook archetypes and the four hook failures
- `05_MARKETING/` : compliant ad copy guide, Skool About page example, pain point template
- `06_BUSINESS_RESEARCH/` : the business and customer research prompt pack

## How to load it

Paste `00_CORE/REANIMATOR_10_MASTER_INSTRUCTIONS.md` into the system or instruction field.
Upload everything else as knowledge files.
Keeping behavior and knowledge apart stops the research and marketing material from overriding the workflow.

The Series Bible is the structural authority for Vertical Series. Once a project is locked, nothing generic should override it.

## Locked fields

Audio mode, character looks, wardrobe, world, locations, palette, lighting, camera language, series arc, episode map, and visual style never change without an explicit request.
