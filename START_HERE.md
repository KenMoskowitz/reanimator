# START HERE: Reanimator 10 for Claude Code

This package moves Reanimator 10 out of the Cowork session and into Claude Code.

## Set up in 3 steps

1. Unzip and drag the REANIMATOR-10 folder into Documents.
2. Open Terminal, type `cd ~/Documents/REANIMATOR-10`, press Return.
3. Type `claude`, press Return, then say "Go".

Claude Code reads CLAUDE.md in that folder, loads the master instructions and Series Bible, and reads the other knowledge files only when a job needs them. You should see the seven project paths.

## What is inside

- CLAUDE.md : the file that tells Claude Code who Reanimator is and how to behave
- 00_CORE to 06_BUSINESS_RESEARCH : the 13 knowledge files, renamed from Hype Jet to Reanimator
- UPLOAD_TXT : the same files as plain .txt, only for uploading to a Claude project. Claude Code ignores it.
- projects/dana-empty-saturday : the test run from this session, so you can say "continue Dana" in the new session
